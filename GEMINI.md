# Apigee AI & Tools Gateway with Google ADK

This repository is an enterprise demonstration and development platform for:
1. **Apigee API Management**: API governance, security, rate-limiting, and developer enablement.
2. **Apigee AI Gateway**: Intelligent auto-routing across Gemini and Anthropic Claude models, product-driven LLM token quotas, Model Armor prompt guardrails, response sanitization, semantic caching, and per-request cost attribution.
3. **Apigee Tools Gateway**: Centralized tool/function execution governance, agent authentication, and native MCP (Model Context Protocol) serving.
4. **Google ADK (Agent Development Kit)**: Dual-pattern Python agents that consume Apigee gateways for models and tools, and are hosted as managed backend microservices fronted by Apigee.
5. **Interactive Demo UI**: React + Vite + Tailwind playground with real-time gateway trace inspection, token/latency/cost metrics, and live policy toggles.

> [!NOTE]
> **Active models:** `gemini-3.5-flash-lite` (`simple`), `gemini-3.6-flash` (`general`), `gemini-3.8-flash`, `gemini-3.1-pro-preview` (`deep_reasoning`), and Anthropic `claude-haiku-5-5` / `claude-opus-5-5` on Vertex AI's global endpoint.
>
> **Token-quota demo:** `claude-haiku-5-5` at **300 tokens/min** on the Engineering & IT and Customer Support & Sales products, enforced by `LLMTokenLimitFlow`. `JS-FormatClaudeResponse` populates `usageMetadata.totalTokenCount` in the target response flow before `LTQ-TokenCount` reads it in PostFlow.
>
> **Rate card:** Read model pricing and cost tiers from [`model_rate_card.json`](apigee/config/model_rate_card.json) (synced to the `ai-model-rates` KVM via [`sync_rate_card.sh`](apigee/scripts/sync_rate_card.sh)). Thinking tokens (`usageMetadata.thoughtsTokenCount`) are billed at the output rate alongside `candidatesTokenCount`. Retired model keys remain in the rate card so historical analytics retain their original pricing.

## Repository Structure Overview
- [`.gemini/rules/`](.gemini/rules/): Coding standards for Apigee XML, Python ADK, and React/Tailwind.
- [`.gemini/skills/`](.gemini/skills/): Procedural playbooks for proxy generation, policy configuration, and agent scaffolding.
- [`.gemini/agents/`](.gemini/agents/): Subagent personas (Apigee Architect, ADK Engineer, Gateway Tester).
- [`apigee/`](apigee/): Apigee X proxy bundles (`proxies/`), API products (`products/`), developer apps (`apps/`), templates, and deployment scripts (`scripts/`).
- [`agents/`](agents/): Python ADK agent microservice (FastAPI + Cloud Run) using the Dual-Pattern.
- [`ui/`](ui/): React + Vite + Tailwind demo playground with live gateway telemetry, served in production by [`server.js`](ui/server.js) on Node.

## Core Development Guidelines

1. **Apigee Standards**: Keep proxy bundles compliant with Apigee X directory structures (`apiproxy/{proxies,targets,policies,resources}`). Name policies with the established type prefixes (`AM-`, `CORS-`, `DC-`, `DJWT-`, `EV-`, `JS-`, `KVM-`, `LTQ-`, `ML-`, `MLC-`, `OAS-`, `QC-`, `RF-`, `SCL-`, `SCP-`, `SMR-`, `SUP-`, `VA-` in `ai-gateway-v1`, plus `PP-` and `Q-` in MCP proxies). [`apigee/templates/ai-gateway/policies/`](apigee/templates/ai-gateway/policies/) is a separate `apigee-go-gen` YAML template set with its own naming conventions.

2. **Product-Driven Quotas & Budgets**: LLM token limits live in `llmOperationGroup.operationConfigs[].llmTokenQuota` in [`apigee/products/`](apigee/products/) and are read dynamically by `LTQ-TokenEnforce` and `LTQ-TokenCount`. Developer budgets live in the product attributes `developer.budget.limit` / `.interval` / `.timeunit` (Engineering & IT `$20/month`, Analysts & Knowledge Workers `$10/month`, Customer Support & Sales `$5/month`) and are enforced by `QC-EnforceBudgetLimit` and `QC-DeductBudget`.

3. **Product-Driven Auto-Routing**: Each persona AI product declares `routing.model.coding`, `routing.model.deep_reasoning`, `routing.model.simple`, and `routing.model.general`. [`AutoRouting.js`](apigee/proxies/ai-gateway-v1/apiproxy/resources/jsc/AutoRouting.js) resolves `verifyapikey.VA-VerifyAPIKey.apiproduct.routing.model.<category>` directly and falls back to `routing.model.general`.

4. **Semantic Cache Isolation**: `AM-SetCacheHitExpected` constructs `flow.cacheKey` scoped by API product, route, and `systemInstruction` hash (`flow.sys_tag`). `SCL-Semantic-Cache-Lookup` and `SCP-Semantic-Cache-Populate` skip requests that declare `tools` (`flow.has_tools == "true"`), and `SMR-SanitizeModelResponse` runs before `SCP-Semantic-Cache-Populate`.

5. **ADK Dual-Pattern**: Route agent model calls through the AI Gateway and tool calls through the Tools Gateway. Do not hardcode direct Vertex AI or backend URLs in the agent core.

6. **Traceability**: Gateway responses carry `x-gateway-*` trace headers set by [`AM-SetResponseHeaders`](apigee/proxies/ai-gateway-v1/apiproxy/policies/AM-SetResponseHeaders.xml) (`x-gateway-model`, `x-gateway-provider`, `x-auto-routed`, `x-gateway-cached`, `x-gateway-total-tokens`, `x-gateway-cost-usd`, etc.). Preserve these headers; the UI trace inspector and test suites depend on them.

7. **Entitlements & Resource Globs**: Grant each model explicitly by name (`/models/<model>:*`). Apigee's `*` matches within a single path segment and requires at least one trailing character, so `/auto` and `/auto:*` are declared as separate `operationConfigs` with equal quotas, and each `operationConfig` contains exactly one `llmOperation`.

8. **Unified AI Ingress Surface**: `ai-gateway-v1` exposes `POST /ai/v1/auto` and `POST /ai/v1/models/{model}:generateContent` using the Gemini `contents` payload format for both Gemini and Claude models (`JS-ClaudeRequestPrep` and `JS-FormatClaudeResponse` translate requests, responses, tool calls, and signed thinking blocks).

9. **Ask Apigee Sandbox Isolation**: The Admin Console's Ask Apigee assistant (`ui/server/adminAgentService.js`) writes only to `(Dev)` product clones pinned to the `dev` environment (`assertWritableDevProduct` + `assertDevOnlyEnvironments`). Production product changes go through pull requests against `apigee/products/`.

10. **Secrets & Configuration**: Never commit credentials, consumer keys, or private project identifiers. Environment-specific values come from `.env` (see `.env.example`) via `scripts/lib/config.sh`, `scripts/lib/deploy_config.py`, and `ui/server/deployConfig.js`.

11. **Validation & Documentation**: Run `npm test` and `npm run build` in `ui/` and `python3 apigee/scripts/validate_bundle.py` before deploying. Update [`README.md`](README.md) and [`docs/`](docs/) whenever proxy policies, API products, models, rate cards, or UI behaviour change.
